# solution/ — 03-context

Тук няма решение в `main`.

Решенията на упражненията се публикуват на клон `solutions/03` и се сливат в `main`
**след крайния срок** на упражнението. Докато срокът тече, тази папка съдържа само тази
бележка.

За `03-context` „решението" е дизайн-документ + две независими агентни изпълнения +
анализ на разликите, всичко това в `exercise/`, което минава `npm test` изцяло.
