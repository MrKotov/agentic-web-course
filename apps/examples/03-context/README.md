# 03 — Дизайн преди код

**Цел.** Същата задача, две коринки: единия без дизайн-документ, другия с подробна спецификация предварително. Вижте разликата в това, което агентът произвежда — изводи, които да защитите на устния изпит.

**Очакван резултат.** Дизайн-документ, две независими изпълнения (едното произволно, другото по дизайна), резултатите сравнени и задокументирани.

---

## Това е упражнение 2

За проверка се очаква:

- Дизайн-документ присъства и не е тривиален.
- Сградата (или две) работи; `npm test` минава.
- И двата изхода на агента са налични (с и без дизайн) за `diff`.

За защита трябва да можете да обясните:
- Какво е спечелено добавянето на дизайна пред кода.
- Конкретни разлики в поведението на агента.
