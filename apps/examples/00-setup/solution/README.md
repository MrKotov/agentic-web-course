# solution/ — 00-setup

Тук няма решение в `main`.

Решенията на упражненията се публикуват на клон `solutions/<номер>` и се сливат в `main`
**след крайния срок** на съответното упражнение. Докато срокът тече, папката съдържа само
тази бележка.

За `00-setup` „решението“ е самата работеща среда: `npm run check` без нито една грешка.
