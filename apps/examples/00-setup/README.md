# 00 — Настройка на средата

**Цел.** За под 15 минути на лабораторна машина: работеща среда, собствен безплатен ключ
към доставчик на модели, и една успешна заявка.

**Очакван резултат.** `npm run check` минава всички проверки, а `npm run demo` печата
отговор на модел, без да пипа мрежата.

---

## Стъпки

1. Отворете хранилището в devcontainer (VS Code → *Reopen in Container*, или GitHub
   Codespaces). Ако devcontainer не тръгва на лабораторната машина, вижте
   `.devcontainer/README.md` — работи и с чист Node 24.12.0.

2. Вземете ключ от <https://openrouter.ai/keys>. Регистрацията е безплатна и **не иска
   карта**. Ключът започва със `sk-or-v1-`.

3. Копирайте примерния файл и попълнете ключа:

   ```bash
   cd 00-setup
   cp .env.example .env
   # отворете .env и сложете ключа на реда OPENROUTER_API_KEY=
   ```

4. Пуснете проверката:

   ```bash
   npm ci        # само първия път
   npm run check
   ```

5. Пуснете демото:

   ```bash
   npm run demo
   ```

6. По желание, една истинска заявка към доставчика:

   ```bash
   npm run check:live
   ```

---

## Какво трябва да видите

`npm run check` завършва с:

```
Всичко е наред. Следваща стъпка: `npm run demo`, после lecture 01-variance.
```

`npm run demo` печата prompt-а, отговора и броя токени, и накрая реда
`(запис — нула мрежови заявки, нула стотинки)`.

---

## Правила за ключа

- `.env` **никога** не се комитва. Вече е в `.gitignore`; проверката го потвърждава.
- Ключът е ваш и лимитите са ваши. Ако го споделите, чуждите заявки ядат вашия лимит.
- Ако случайно комитнете ключ: анулирайте го в OpenRouter **веднага** и създайте нов.
  Изтриването на файла не помага — ключът остава в историята.
- Курсът не изисква нито един платен ресурс. Ако нещо иска карта, това е грешка в
  материала — съобщете.

## Ако нещо не тръгне

| Съобщение | Какво значи |
|---|---|
| `node_version` е ГРЕШ | Не сте в devcontainer-а. `nvm install 24.12.0 && nvm use 24.12.0`. |
| `env_file_exists` е ГРЕШ | Не сте копирали `.env.example` в `.env`. |
| `api_key_present` е ГРЕШ | Ключът е празен, с интервал/кавички, или не е от OpenRouter. |
| HTTP 429 при `check:live` | Изчерпан безплатен лимит. Изчакайте минута. |
| Мрежова грешка при `check:live` | Университетското прокси блокира доставчика. Демотата пак работят — те са записи. |
