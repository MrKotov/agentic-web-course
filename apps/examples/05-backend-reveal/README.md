# 05 — Бекенд: развързване

**Цел.** Разоръжение на произведеният от агента код — линия по линия, защо работи това,
как е произведено, как се прави грешка. Лекция е, не упражнение.

**Очакван резултат.** Коментирана кодова база — реален бекенд от упражнение 3, разрез
с обяснения по HTTP, ORMs, миграции, автентификация.

---

## Това не е упражнение

Папката е материал за лекция 5 и 6. Съдържа реални производства от студентски упражнение 3,
развързани страна по страна със спецификацията на MCP и жизненния цикъл на HTTP заявка.

Окончателната версия се строи **след** като упражнение 3 е оценено, защото трябва да видим
какво студентите са натворили. Преди това папката е шаблон.
