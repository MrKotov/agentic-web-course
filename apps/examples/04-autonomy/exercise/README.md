# exercise/ — 04-autonomy

Задачата: напишете характеристика на база инструкции към агент, регистрирайте всичкото
което чести по пътя.

## Как да работите

1. Напишете инструкции (спецификация на лекционен английски, доста подробна) на агент.
   Той трябва да произведе код или конфигурация, която реализира тази характеристика.
2. Настройте контролни точки — места, където агентът трябва да докладва, преди да
   продължи (например „преди да си напишете базата, разчетете дали трябва миграция").
3. Пуснете агента, регистрирайте всяко съобщение, което получавате (това е вашият
   prompt log).
4. Напишете тестове, които доказват, че характеристиката работи.

Готови сте, когато:

- `npm test` минава.
- Prompt log присъства и е пълен (начало → край, всички съобщения).

За защита трябва да обясните контролните си точки.
