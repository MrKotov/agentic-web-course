Тук няма решение в `main`.

Решенията на упражненията се публикуват на клон `solutions/04` и се сливат в `main`
**след крайния срок** на упражнението. Докато срокът тече, тази папка съдържа само тази
бележка.

За `04-autonomy` „решението" е инструкции на агент + код, който той произвежда +
контролни точки + пълен prompt log + тестове, всичко това в `exercise/`, което минава
`npm test` изцяло.
