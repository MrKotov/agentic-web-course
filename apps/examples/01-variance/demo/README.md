# demo/ — какво пуска преподавателят

```bash
npm run demo
```

Един prompt, десет отговора от `recordings/ten-runs.json`, после диф на схемите.
Нула мрежови заявки, нула ключове — върви и при мъртва мрежа в залата.

Записът е направен веднъж, на 2026-09-08, с `temperature: 0.7`. Тези десет отговора са
истински по форма: преименувано поле, число станало низ, масив станал скалар, JSON увит в
```` ```json ```` ограда, JSON вложен под ключ `book`, измислено поле, липсващо поле.

Извън залата, с попълнен `.env`:

```bash
npm run demo:live
```

Десет истински заявки, последователно. Числата ще са други — това е целият смисъл.
