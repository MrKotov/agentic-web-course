# solution/ — 02-mcp-server

Тук няма решение в `main`.

Решенията на упражненията се публикуват на клон `solutions/02` и се сливат в `main`
**след крайния срок** на упражнението. Докато срокът тече, тази папка съдържа само тази
бележка — умишлено, за да не изтече работещ `src/server.ts` в публичната история преди
всички да са предали.

За `02-mcp-server` „решението" е сървър в `exercise/src/server.ts`, който минава
`npm test` в `02-mcp-server/` изцяло: валиден `tools/list`, правилен `word_count` за
зададените примери, и оцеляване при извикване на непознат инструмент.
