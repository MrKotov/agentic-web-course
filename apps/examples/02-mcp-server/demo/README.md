# demo/ — какво пуска преподавателят

```bash
npm run demo
```

Стартира `ping-server.ts` — пълен, работещ, ръчно написан MCP сървър с инструмент `ping`
(нарочно различен от `word_count` в упражнението, за да не издава решението) — и го
изпитва стъпка по стъпка: `initialize`, `tools/list`, успешен `tools/call`, `tools/call`
към несъществуващ инструмент, и накрая пак `tools/list`, за да се види, че сървърът е още
жив.

Нула мрежови заявки, нула ключове — по дизайн, не защото е записано. MCP говори по локален
stdin/stdout, не по мрежата, така че това демо няма как да пострада от изключен интернет
в залата.

Всеки ред, който сървърът получава (`-->`) и връща (`<--`), се отпечатва, за да се виждат
суровите JSON-RPC съобщения — точно това, което автоматичният оценител размества зад
кулисите на упражнението.
