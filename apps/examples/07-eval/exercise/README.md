# exercise/ — 07-eval

Задачата: прочетете даден лог, намерете проблемите, разберете кои е истински.

## Как да работите

1. Откритрете `logs/` директория (съдържа дебъг и error output от произведен агентен код).
2. За всеки ред, кой излиза подозрително:
   - Напишете какъв проблем виждате.
   - Проверете, че е истински, а не симптом на друг проблем.
   - Документирайте го с цитат от логите.
3. Издайте списък.

Готови сте, когато:

- `npm test` минава (проверява, че няма синтаксис грешка в вашия списък).
- Списъкът е разделен на две колони: истински проблеми и лъжа.

За защита трябва да можете да обясните разликата във всеки случай.
