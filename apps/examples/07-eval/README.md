# 07 — Оценка на резултатите

**Цел.** Да видите, че произведеният от агента код съдържа грешки. Да научите да
читате дебъг-лог и трагедийска информация със ясна глава. Да разберете разликата между
„проблем, който виждам" и „проблем, който наистина е".

**Очакван резултат.** Списък на намирките, разделени на: вярно съществуващи проблеми,
неправилни алармости, и край. Резултат е защитима.
